# Django Admin – Overview & Customization

## 🎯 Main Goal

Understand:

- What Django Admin is
    
- Why it’s powerful
    
- How to enable it
    
- How to customize it
    

---

## 🧠 What is Django Admin?

Django Admin is a built-in **graphical user interface (GUI)** that allows you to manage your models.

It automatically provides:

- Create
    
- Read
    
- Update
    
- Delete (CRUD)
    

operations for your database models.

You define models → Django automatically generates a management interface.

This is one of the biggest reasons developers love Django.

---

## 🔐 Authentication System

Django Admin includes a built-in authentication system:

- Login required
    
- Protected access
    
- Only authorized users can access the admin panel
    

It’s secure by default.

---

## ⚙️ How to Enable Django Admin

### 1️⃣ Open/Create `admin.py` inside your app

Example:

```
core/admin.py
```

### 2️⃣ Register your model

```python
from django.contrib import admin
from .models import Recipe

admin.site.register(Recipe)
```

Every model must be registered to appear in the admin panel.

---

# 🎛 Customizing Django Admin

To customize the interface, create a custom admin class:

```python
from django.contrib import admin
from .models import Recipe

class RecipeAdmin(admin.ModelAdmin):
    pass

admin.site.register(Recipe, RecipeAdmin)
```

Now you can control how the model appears.

---

## Important Customization Options

### 1️⃣ `ordering`

Controls how objects are sorted in list view.

```python
ordering = ['name']
```

---

### 2️⃣ `list_display`

Controls which fields appear in the list page.

```python
list_display = ['id', 'name', 'price']
```

You usually don’t want to display every field  
(example: never display encrypted passwords).

---

### 3️⃣ `fieldsets`

Controls layout of the edit/update page.

Used to:

- Group fields
    
- Add section titles
    
- Structure the form
    

Example:

```python
fieldsets = (
    (None, {'fields': ('email', 'password')}),
    ('Personal Info', {'fields': ('first_name', 'last_name')}),
)
```

---

### 4️⃣ `readonly_fields`

Makes fields visible but not editable.

```python
readonly_fields = ['last_login']
```

Useful for:

- Auto-generated fields
    
- System-managed values
    

---

### 5️⃣ `add_fieldsets`

Customize the **add page only**.

Often used for user registration forms.

Example:

```python
add_fieldsets = (
    (None, {
        'classes': ('wide',),
        'fields': ('email', 'password1', 'password2'),
    }),
)
```

---

# 🧠 Key Takeaways

- Django Admin is an automatic CRUD interface.
    
- You must register models in `admin.py`.
    
- Use `ModelAdmin` to customize appearance and behavior.
    
- You can control list view, ordering, layout, and edit permissions.
    
- Extremely powerful with very little code.
