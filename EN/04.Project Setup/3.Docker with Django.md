# 🐳 How Docker Works with Django — Obsidian Notes

> 🎯 Goal: Understand how Docker and Django work together to create a consistent, portable, and professional development environment.

---

# 🚀 Why Use Docker with Django

Docker provides major advantages when developing Django applications.

---

## 1️⃣ Consistent Environment 🔁

> 💡 Docker ensures the same environment in development and production.

Without Docker:

- Different Python versions ❌
    
- Different dependencies ❌
    
- Application may break ❌
    

With Docker:

- Same Python version ✅
    
- Same dependencies ✅
    
- Same behavior everywhere ✅
    

---

## 🧠 Mental Model

```
Docker container = identical environment everywhere
```

---

## 2️⃣ Easier Collaboration 👥

Without Docker:

- Other developers must install dependencies manually
    
- May cause compatibility issues
    

With Docker:

- All dependencies included in container
    
- Other developers just run Docker
    
- Project works immediately
    

---

## 3️⃣ Dependencies Managed Automatically 📦

Docker stores dependencies inside:

- Dockerfile
    
- Docker image
    

Example dependencies:

- Python
    
- Django
    
- System libraries
    
- Database drivers
    

---

## 4️⃣ Easy Cleanup 🧹

Without Docker:

- Dependencies installed on your system
    
- Hard to remove later
    

With Docker:

- Everything inside container
    
- Just delete container → system clean
    

---

# ⚠️ Drawback of Using Docker

## Problem: VS Code cannot directly access Python interpreter inside container

This affects:

- Debugger
    
- Python extensions
    
- IntelliSense (sometimes)
    

---

## ✅ Solution Used in This Course

Use terminal to run commands through Docker.

Example:

```bash
docker compose run app command
```

---

## 🧠 Mental Model

```
VS Code → edit code
Docker → run code
Terminal → control Docker
```

---

# 🧱 Dockerfile — Defines Environment

## 📌 What is Dockerfile?

Dockerfile is a file that defines how Docker builds your project environment.

It contains:

- Base image
    
- Dependencies
    
- Setup instructions
    

---

## Example structure

```
Dockerfile
```

Steps inside Dockerfile:

1. Choose base image
    

Example:

```
python:3.11
```

2. Install dependencies
    

Example:

```
Django
PostgreSQL drivers
System packages
```

3. Create Linux user
    

Used to run application safely.

---

## 🧠 Mental Model

```
Dockerfile = recipe for creating environment
```

---

# ⚙️ docker-compose.yml — Runs the Application

## 📌 What is docker-compose?

docker-compose defines how containers run.

It manages services such as:

- Django app
    
- Database
    

---

## Defines services

Example service name:

```
app
```

---

## Defines port mapping 🌐

Example:

```
8000:8000
```

This allows browser to access Django.

---

## Defines volume mapping 📁

Volume mapping connects:

```
Local project code → Docker container
```

This ensures code changes update immediately.

---

## 🧠 Mental Model

```
docker-compose = manager that runs containers
```

---

# ▶️ Running Django Commands Using Docker

Instead of running commands directly:

```
python manage.py command
```

You run commands through Docker:

---

## Example command

```bash
docker compose run --rm app sh -c "python manage.py collectstatic"
```

---

## Explanation of parts

### docker compose run

Runs a command inside container

---

### --rm

Removes container after command finishes

Prevents unused containers from accumulating

---

### app

Service name defined in docker-compose.yml

---

### sh -c

Runs command inside container shell

---

### "python manage.py collectstatic"

Actual Django command executed

---

## Command Structure Summary

```bash
docker compose run --rm app sh -c "Django command"
```

---

## Example commands

Run migrations:

```bash
docker compose run --rm app sh -c "python manage.py migrate"
```

Create superuser:

```bash
docker compose run --rm app sh -c "python manage.py createsuperuser"
```

Run tests:

```bash
docker compose run --rm app sh -c "python manage.py test"
```

Workflow:

```
Dockerfile → defines environment 🧱
docker-compose.yml → runs containers ⚙️
Docker → executes Django 🐳
Terminal → sends commands ⌨️
```
