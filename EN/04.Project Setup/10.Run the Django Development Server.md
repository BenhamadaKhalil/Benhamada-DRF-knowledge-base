# 🚀 Run the Django Development Server (with Docker)

> 🎯 Goal: Start the Django dev server inside Docker and access it from your browser.

---

# ▶️ 1) Start the Server

In your project root, run:

```bash
docker compose up
```

---

## 🧠 What this does

- 🐳 Starts all services defined in `docker-compose.yml`
    
- In our case, it starts the **app** service
    
- Runs the default `command` we defined earlier:
    

```yaml
command: >
  sh -c "python manage.py runserver 0.0.0.0:8000"
```

So Docker:

- Builds the container (if needed)
    
- Starts Django development server
    
- Streams logs to your terminal
    

---

# 🌍 2) Open the Project in the Browser

Go to:

```
http://127.0.0.1:8000
```

✅ If everything is correct, you will see the **Django default welcome page** 🎉

That means:

- Docker is working
    
- Volume mapping works
    
- Django is running correctly
    
- Port mapping is correct
    

---

# 🔎 3) Understanding the Logs

When the server runs, your terminal shows logs.

Example:

```
Starting development server at http://0.0.0.0:8000/
```

If you refresh the page in the browser:

- You’ll see GET requests appear in the terminal logs.
    

🧠 This confirms:

- The container is handling HTTP requests
    
- Port 8000 is exposed correctly
    

---

# ⛔ 4) Stop the Server

To stop the server:

```
CTRL + C
```

This stops the Docker Compose service.

If you refresh the browser after stopping:  
❌ You’ll see “Site can’t be reached”

---

# 🔁 5) Restart the Server

Simply run again:

```bash
docker compose up
```

Wait a few seconds → refresh the browser → it works again ✅

---

# 🧠 Mental Model

```
Browser → localhost:8000
        ↓
Docker container (port 8000)
        ↓
Django development server
```

---

# ✅ Quick Verification Checklist

- ✅ `docker compose up` runs without errors
    
- ✅ You can access `127.0.0.1:8000`
    
- ✅ Django welcome page appears
    
- ✅ Logs appear in terminal when refreshing
    
- ✅ CTRL+C stops the server
    

---

🎉 At this point:

You officially have:

- Dockerized Django project
    
- Development environment working
    
- Port mapping configured
    
- Volume sync working
    

You now have a **professional-level Django setup**.
