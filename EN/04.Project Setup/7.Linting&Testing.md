# 🧹 1) What is Linting?

## ✅ Definition

**Linting** = running a tool that checks your code formatting and quality.

It can catch:

- 🧠 Python syntax errors
    
- ✍️ typos
    
- 🎨 formatting issues (spaces, line length, etc.)
    

---

# 🧰 2) Linting Tool Used: Flake8 🪶

We will use:

- ✅ **Flake8** (`flake8`)
    
- Simple and popular for Python projects
    

> [!note] Why Flake8?  
> It quickly reports common Python issues (style + errors) without heavy configuration.

---

# ▶️ 3) Running Flake8 with Docker Compose

We run commands inside the container using Docker Compose.

## ✅ Lint command structure

```bash
docker compose run --rm app sh -c "flake8"
```

### 🧠 Meaning of each part

- `docker compose run` → run a one-time command in a container
    
- `--rm` → delete the container after finishing (avoids clutter)
    
- `app` → the service name from `docker-compose.yml`
    
- `sh -c "flake8"` → run Flake8 inside the container
    

---

# 📌 4) Understanding Flake8 Output

## ✅ If you see errors

It means your code has linting problems.

Typical output contains:

- 📄 file path
    
- 📍 line number
    
- ❌ error code + message
    

Example idea:

- “Missing whitespace after comma” → means you forgot a space after `,`
    

✅ You fix the issue and run `flake8` again.

---

## 🧠 Pro Tip: Fix from Bottom to Top ⬆️

> [!tip] Fix linting errors from the bottom first  
> Because fixing an error may add/remove lines → line numbers above might shift.
> 
> ✅ Bottom → Top keeps line references correct.

# 🧪 5) Testing Tool Used: Django Test Suite

We will use Django’s built-in testing framework:

- ✅ Comes with Django
    
- ✅ Used for unit tests
    
- ✅ Tests will be organized per Django app
    

---

# ▶️ 6) Running Django Tests with Docker Compose

## ✅ Test command

```bash
docker compose run --rm app sh -c "python manage.py test"
```

### 🧠 What it does

- Runs all unit tests in the Django project
    
- Reports passed/failed tests

> [!example] Typical development cycle
