# 🛠️ Required Tools for Django Development

> 📌 Before starting Django development, you must install some essential tools.  
> These tools allow you to write code, run your application, and manage your project.

---

## 💻 1. Code Editor — Visual Studio Code

## 📌 What is it?

A **code editor** is software used to write and edit your code.

The recommended editor is:

> 🟦 **Visual Studio Code (VS Code)**

---

## 🎯 Why VS Code?

VS Code provides:

- 🧠 Syntax highlighting
    
- 🔍 Error detection
    
- 🧩 Extensions support
    
- ⚡ Fast performance
    
- 🐍 Excellent Python & Django support
    

---

## 📦 What you'll use it for

- Writing Django code
    
- Editing project files
    
- Managing your project structure
    

---

## 🧠 Mental Model

> VS Code = Your programming workspace

---

## 🐳 2. Docker Desktop

## 📌 What is Docker?

Docker is a tool that allows you to run applications in **containers**.

Containers include:

- Your Django app
    
- Your database
    
- All dependencies
    

---

## 🎯 Why Docker is important

Docker ensures:

- ✅ Same environment everywhere
    
- ✅ Easy setup
    
- ✅ Easy deployment
    
- ✅ No dependency conflicts
    

---

## 📦 What you'll run with Docker

- Django application
    
- PostgreSQL database
    

---

## 🧠 Mental Model

> Docker = Isolated box that contains your entire application

---

## 🌿 3. Git — Version Control System

## 📌 What is Git?

Git is a tool used to **track changes in your code**.

It allows you to:

- Save versions of your project
    
- Track modifications
    
- Collaborate with others
    

---

## 📦 Git is required for GitHub

You need Git to:

- Clone repositories
    
- Commit changes
    
- Push code to GitHub
    

---

## 💻 Example commands

Clone project:

```bash
git clone https://github.com/project/repo.git
```

Save changes:

```bash
git add .
git commit -m "Added feature"
git push
```

---

## 🧠 Mental Model

> Git = History tracker for your code

---

## 🧱 How These Tools Work Together

```
VS Code → Write code 💻
Docker → Run application 🐳
Git → Track and save code 🌿
```

---

## 📋 Summary Table

|Tool|Role|
|---|---|
|💻 VS Code|Code editor|
|🐳 Docker|Runs application containers|
|🌿 Git|Tracks and manages code changes|

---

## 🎯 Final Overview

Before continuing the Django course, make sure you have installed:

- 💻 Visual Studio Code
    
- 🐳 Docker Desktop
    
- 🌿 Git
    

These are essential tools for professional Django development.
