# 🔍 Verify Installation of Development Tools

> 📌 Before starting Django development, you must verify that all required tools are installed and working correctly.

Tools to verify:

- 💻 Visual Studio Code
    
- 🐳 Docker & Docker Compose
    
- 🌿 Git
    

---

## 💻 1. Verify Visual Studio Code (VS Code)

## ✅ How to check

### On Windows 🪟

- Open **Start Menu**
    
- Search for: `Visual Studio Code`
    
- Click to open it
    

### On Mac 🍎

- Open **Launcher**
    
- Type: `VS`
    
- Select **Visual Studio Code**
    

---

## ✅ Successful installation indicators

You should see:

- VS Code opens normally
    
- Welcome screen appears
    
- Code editor interface loads
    

---

## 🧠 Mental Model

> 💻 VS Code opens = Code editor is ready ✔

---

## 🐳 2. Verify Docker Installation

## Step 1 — Check Docker Desktop is running

Look for Docker icon:

- 🪟 Windows → System tray
    
- 🍎 Mac → Top menu bar
    

Docker should show:

```
Docker Desktop is running
```

---

## Step 2 — Check Docker version using terminal

Open terminal or command prompt and run:

```bash
docker --version
```

---

## ✅ Expected output example

```bash
Docker version 24.0.5
```

✔ Docker is installed correctly.

---

## 🧱 3. Verify Docker Compose Installation

Docker Compose is installed with Docker Desktop.

Run:

```bash
docker-compose --version
```

or:

```bash
docker compose version
```

---

## ✅ Expected output example

```bash
Docker Compose version v2.20.0
```

✔ Docker Compose is working.

---

## 🧠 Mental Model

- 🐳 Docker → Runs containers
    
- 🧱 Docker Compose → Manages containers
    

---

## 🌿 4. Verify Git Installation

Run:

```bash
git --version
```

---

## ✅ Expected output example

```bash
git version 2.42.0
```

✔ Git is installed correctly.

---

## ⚠️ Troubleshooting

If a command does not work or shows error:

Example:

```bash
command not found
```

👉 Solution:

- Install the missing tool
    
- Restart terminal
    
- Check official documentation
