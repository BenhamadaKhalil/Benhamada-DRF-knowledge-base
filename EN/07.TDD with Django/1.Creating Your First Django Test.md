# 🧪 Creating Your First Django Test

We’re going to:

1. Create a simple function (`add`)
    
2. Write a test for it
    
3. Run the test using Docker
    
4. See it pass ✅ and fail ❌
    

---

## 📁 Step 1 — Create the Code to Test

Inside:

```
app/app/
```

Create a file:

```
calc.py
```

### 🧮 `calc.py`

```python
"""
Calculator functions
"""

def add(x, y):
    """Add x and y and return result"""
    return x + y
```

Very simple. Just adds two numbers.

---

## 📁 Step 2 — Create the Test File

Inside the same folder:

```
app/app/
```

Create:

```
tests.py
```

### 🧪 `tests.py`

```python
"""
Sample tests
"""

from django.test import SimpleTestCase
from app import calc


class CalcTests(SimpleTestCase):
    """Test the calc module"""

    def test_add_numbers(self):
        """Test adding numbers together"""
        result = calc.add(5, 6)
        self.assertEqual(result, 11)
```

---

## 🧠 What’s Happening Here?

- `SimpleTestCase` → Used when no database is needed
    
- `calc.add(5, 6)` → Calls our function
    
- `assertEqual(result, 11)` → Checks if the output is correct
    

If it’s not 11 → test fails ❌  
If it is 11 → test passes ✅

---

## 🚀 Step 3 — Run the Test with Docker

Because we’re using Docker, run:

```bash
docker-compose run --rm app sh -c "python manage.py test"
```

### What this does:

- `docker-compose run` → Runs the service
    
- `--rm` → Deletes container after running
    
- `app` → Service name
    
- `sh -c` → Run shell command
    
- `"python manage.py test"` → Runs Django test runner
    

---

## ✅ Expected Output (Passing)

```
Ran 1 test in 0.001s

OK
```

Boom. Test passed.

---

## ❌ Make It Fail (On Purpose)

Change:

```python
self.assertEqual(result, 11)
```

to:

```python
self.assertEqual(result, 12)
```

Run the test again:

```bash
docker-compose run --rm app sh -c "python manage.py test"
```

### Now you’ll see something like:

```
AssertionError: 11 != 12
FAILED (failures=1)
```

This means:

- Your test logic works
    
- It correctly detects incorrect results
    

---

## 🔁 Fix It Back

Change it back to:

```python
self.assertEqual(result, 11)
```

Run again → passes ✅

---

## 💡 Important Concepts You Just Learned

- Django automatically discovers tests in `tests.py`
    
- Test methods must start with `test_`
    
- `SimpleTestCase` = no database required
    
- `assertEqual()` is how you verify behavior
    
- Docker runs tests exactly like production environment
