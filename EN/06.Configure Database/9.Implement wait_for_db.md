## Imports Needed

```python
import time
from psycopg2 import OperationalError as Psycopg2Error
from django.db.utils import OperationalError
from django.core.management.base import BaseCommand
```

### Why two errors?
During DB startup:
- sometimes psycopg2 throws `OperationalError` (connection refused)
- sometimes Django throws `django.db.utils.OperationalError` (DB up but not fully ready)

We catch both.

---

# 🧠 Command Implementation (Loop + Retry)

Core logic:

```python
class Command(BaseCommand):
    """Django command to wait for the database."""

    def handle(self, *args, **options):
        """Entry point for command."""
        self.stdout.write("Waiting for database...")

        db_up = False
        while not db_up:
            try:
                self.check(databases=["default"])
                db_up = True
            except (Psycopg2Error, OperationalError):
                self.stdout.write("Database unavailable, waiting 1 second...")
                time.sleep(1)

        self.stdout.write(self.style.SUCCESS("Database available!"))
```

### What happens?
- prints “Waiting for database…”
- keeps calling `self.check(databases=["default"])`
- if exceptions occur → sleeps 1 sec and retries
- once DB responds successfully → prints success message and exits
