# Django – Creating the Core App for Custom Commands

## 📌 Lesson Goal

Before creating the `wait_for_db` management command, we need a dedicated Django app to store:

- Custom management commands
- Shared models (later)
- Core project logic

We will create a new app called:

```
core
```

---

# 🐳 Step 1 – Create the Core App (Using Docker)

Run inside your project root:

```bash
docker-compose run --rm app sh -c "python manage.py startapp core"
```

### Breakdown of the command:

- `docker-compose run` → run a one-time container
- `--rm` → remove container after execution
- `app` → service name
- `python manage.py startapp core` → Django command

This creates a new Django app folder:

```
core/
```

---

# 📁 Step 2 – Clean Up Unnecessary Files

Inside `core/`, delete:

- `views.py` → we won’t use views in this app
- `tests.py` → we will organize tests differently

---

# 🧪 Step 3 – Create Proper Test Structure

Create inside `core/`:

```
core/
└── tests/
    └── __init__.py
```

### Why?

Instead of one single `tests.py` file:
- We use a `tests/` directory
- Better organization for larger projects
- Industry-style structure

---

# ⚙️ Step 4 – Register the App in settings.py

Open:

```
app/app/settings.py
```

Add `"core"` to `INSTALLED_APPS`:

```python
INSTALLED_APPS = [
    ...
    'core',
]
```

### Why?

If you don’t register it:
- Django won’t recognize the app
- Models won’t migrate
- Commands won’t be discovered

---

# 🧠 Why Create a Core App?

We could technically put code anywhere…
But this is good architecture.

The `core` app will later hold:

- Custom management commands (`wait_for_db`)
- Shared models (e.g., User model)
- Centralized reusable logic

Keeps project clean and scalable.

---

# 🏗️ Final Project Structure (After This Step)

```
app/
├── app/
│   └── settings.py
├── core/
│   ├── __init__.py
│   ├── models.py
│   ├── tests/
│   │   └── __init__.py
│   └── ...
└── manage.py
```

---

# 🔥 Key Takeaways

- Always create Django apps using `manage.py`
- Use Docker when inside a containerized project
- Clean unused template files
- Organize tests in a directory
- Add new apps to `INSTALLED_APPS`
