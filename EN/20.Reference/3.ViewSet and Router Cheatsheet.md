## 🪜 Pick a rung

| You need | Use |
| --- | --- |
| Full CRUD on a model | `ModelViewSet` |
| CRUD minus create | mixins + `GenericViewSet` |
| Read-only resource | `ReadOnlyModelViewSet` |
| A collection URL (`GET`+`POST`) | `ListCreateAPIView` |
| A detail URL (`GET`/`PUT`/`PATCH`/`DELETE`) | `RetrieveUpdateDestroyAPIView` |
| One odd endpoint (`/token/`, `/export/`) | `APIView` |
| A function, quickly | `@api_view(["GET"])` |

## 📦 Generic views

| Class | Methods | URL shape |
| --- | --- | --- |
| `CreateAPIView` | POST | `/things/` |
| `ListAPIView` | GET | `/things/` |
| `RetrieveAPIView` | GET | `/things/{id}/` |
| `UpdateAPIView` | PUT, PATCH | `/things/{id}/` |
| `DestroyAPIView` | DELETE | `/things/{id}/` |
| `ListCreateAPIView` | GET, POST | `/things/` |
| `RetrieveUpdateAPIView` | GET, PUT, PATCH | `/things/{id}/` |
| `RetrieveDestroyAPIView` | GET, DELETE | `/things/{id}/` |
| `RetrieveUpdateDestroyAPIView` | GET, PUT, PATCH, DELETE | `/things/{id}/` |

```python
class ManageUserView(generics.RetrieveUpdateAPIView):
    """Manage the authenticated user."""
    serializer_class = UserSerializer
    authentication_classes = [TokenAuthentication]
    permission_classes = [IsAuthenticated]

    def get_object(self):
        return self.request.user       # no {id} in the URL — /me/ resolves to you
```

## 🧩 Mixins

| Mixin | Adds | HTTP |
| --- | --- | --- |
| `ListModelMixin` | `list()` | GET (collection) |
| `CreateModelMixin` | `create()` | POST |
| `RetrieveModelMixin` | `retrieve()` | GET (detail) |
| `UpdateModelMixin` | `update()`, `partial_update()` | PUT, PATCH |
| `DestroyModelMixin` | `destroy()` | DELETE |

```python
class TagViewSet(mixins.DestroyModelMixin,
                 mixins.UpdateModelMixin,
                 mixins.ListModelMixin,
                 viewsets.GenericViewSet):     # ← base always LAST
    ...
```

## 🧭 Routers

```python
# app/recipe/urls.py
from django.urls import path, include
from rest_framework.routers import DefaultRouter

from recipe import views

router = DefaultRouter()
router.register("recipes", views.RecipeViewSet)
router.register("tags", views.TagViewSet)
router.register("ingredients", views.IngredientViewSet)

app_name = "recipe"

urlpatterns = [
    path("", include(router.urls)),
]
```

| Router | Gives you |
| --- | --- |
| `SimpleRouter` | just the routes |
| `DefaultRouter` | routes **plus** a browsable API root listing every endpoint |

### Generated URL names

| Registered as | List name | Detail name |
| --- | --- | --- |
| `router.register("recipes", RecipeViewSet)` | `recipe:recipe-list` | `recipe:recipe-detail` |
| `router.register("tags", TagViewSet)` | `recipe:tag-list` | `recipe:tag-detail` |

```python
reverse("recipe:recipe-list")
reverse("recipe:recipe-detail", args=[recipe.id])
```

> [!WARNING] Two required pieces people forget
> - `app_name = "recipe"` — without it, `reverse("recipe:…")` raises `NoReverseMatch` and the error never mentions `app_name`.
> - a `queryset` class attribute on the viewset — the router derives the basename from it. Without one: `basename argument not specified`. Pass `basename="recipe"` to `register()` if you genuinely have no queryset.

## ⚡ Custom actions

```python
from rest_framework.decorators import action
from rest_framework.response import Response


class RecipeViewSet(viewsets.ModelViewSet):

    @action(methods=["POST"], detail=True, url_path="upload-image")
    def upload_image(self, request, pk=None):
        """Upload an image to a recipe."""
        recipe = self.get_object()
        serializer = self.get_serializer(recipe, data=request.data)

        if serializer.is_valid():
            serializer.save()
            return Response(serializer.data, status=status.HTTP_200_OK)

        return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)
```

| Argument | Effect |
| --- | --- |
| `detail=True` | `/recipes/{pk}/upload-image/` |
| `detail=False` | `/recipes/upload-image/` |
| `url_path="upload-image"` | the URL segment (defaults to the method name) |
| `url_name="upload-image"` | the reverse name → `recipe:recipe-upload-image` |
| `permission_classes=[…]` | override permissions for this action only |
| `serializer_class=…` | override the serializer for this action only |

## 🪝 The hooks worth knowing

```python
class RecipeViewSet(viewsets.ModelViewSet):
    serializer_class = serializers.RecipeDetailSerializer
    queryset = Recipe.objects.all()
    authentication_classes = [TokenAuthentication]
    permission_classes = [IsAuthenticated]

    def get_queryset(self):
        """What this request may see."""
        return (
            self.queryset
            .filter(user=self.request.user)
            .prefetch_related("tags", "ingredients")
            .order_by("-id")
        )

    def get_serializer_class(self):
        """Which shape to use, per action."""
        if self.action == "list":
            return serializers.RecipeSerializer
        elif self.action == "upload_image":
            return serializers.RecipeImageSerializer
        return self.serializer_class

    def perform_create(self, serializer):
        """Inject server-side data on write."""
        serializer.save(user=self.request.user)

    def get_permissions(self):
        """Per-action permissions — returns INSTANCES."""
        if self.action == "destroy":
            return [IsAuthenticated(), IsOwner()]
        return [IsAuthenticated()]

    def get_object(self):
        """Override to resolve the object differently (e.g. /me/)."""
        return super().get_object()
```

| Hook | Called | Use it to |
| --- | --- | --- |
| `get_queryset()` | every list/detail request | **scope data to the user** |
| `get_serializer_class()` | every request | vary the shape per action |
| `get_serializer_context()` | every request | pass extra context to the serializer |
| `perform_create(serializer)` | on POST | set fields the client mustn't send |
| `perform_update(serializer)` | on PUT/PATCH | same, plus cache invalidation |
| `perform_destroy(instance)` | on DELETE | soft delete, cleanup |
| `get_permissions()` | every request | per-action authorization |
| `get_object()` | detail requests | custom lookup |

## 🎯 The three-line summary

```python
def get_queryset(self):
    return self.queryset.filter(user=self.request.user)     # who can SEE it

def perform_create(self, serializer):
    serializer.save(user=self.request.user)                 # who OWNS it

permission_classes = [IsAuthenticated]                      # who can ASK
```

Get those three right and most of your API's correctness follows.
