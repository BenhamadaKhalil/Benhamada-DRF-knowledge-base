# 📖 Glossary

> Every term in this vault, defined once. The ones people nod along to without knowing are marked ⭐.

---

## A

**Action** — a method on a ViewSet mapped to an HTTP request: `list`, `create`, `retrieve`, `update`, `partial_update`, `destroy`, plus anything decorated with `@action`.

**AbstractBaseUser** — the minimal Django user base class. Gives you password handling and `last_login` and nothing else. What you subclass for a [[1.Custom User Model in Django|custom user model]].

**ALLOWED_HOSTS** — the list of `Host` header values Django will serve. With `DEBUG=False`, anything else gets `400`. Blocks host-header poisoning.

**Atomicity** ⭐ — the "A" in ACID. A group of writes either all land or none do. In Django: `transaction.atomic()`. See [[8.Transactions]].

**AUTH_USER_MODEL** — the setting naming your user model. Always reference it via `settings.AUTH_USER_MODEL`, never by direct import.

---

## B

**Basename** — the prefix a router uses for generated URL names (`recipe-list`, `recipe-detail`). Derived from the viewset's `queryset` unless you pass it explicitly.

**Broker** — the queue a task producer writes to and a worker reads from. Redis or RabbitMQ. See [[9.Background Jobs with Celery]].

**Browsable API** — DRF's self-documenting HTML interface, rendered when a browser sends `Accept: text/html`. Excellent in development; usually disabled in production.

---

## C

**CASCADE** — `on_delete` behaviour: deleting the parent deletes the children.

**Celery** — a distributed task queue for running work outside the request cycle.

**collectstatic** — the management command that gathers every app's static files into `STATIC_ROOT` so a web server can serve them.

**Content negotiation** ⭐ — DRF deciding the response format from the `Accept` header. Same view, JSON for an API client, HTML for a browser.

**CSRF** — Cross-Site Request Forgery. A malicious site making authenticated requests using the victim's cookies. Relevant to cookie/session auth, not to token auth.

---

## D

**Deserialization** — JSON → validated Python → model instance. The *write* direction of a serializer.

**Dispatch** — `APIView.dispatch()`, the method that routes a request to `get()` / `post()` and wraps everything in DRF's request/response handling.

**drf-spectacular** — generates an OpenAPI 3 schema from your code, which Swagger UI then renders. See [[2.Automated API Documentation in Django REST Framework]].

---

## E

**Eager loading** ⭐ — fetching related objects up front (`select_related`, `prefetch_related`) instead of lazily one at a time. The cure for [[4.The N+1 Problem|N+1]].

**envsubst** — a shell utility substituting `${VAR}` in a template. Lets one Docker image produce environment-specific config at start time.

**ETag** — a response fingerprint. The client sends it back as `If-None-Match`; an unchanged resource gets `304` and no body.

---

## F

**F() expression** — a reference to a database column inside a query, so arithmetic happens in SQL rather than Python. `F("views") + 1` is race-free.

**flake8** — the linter this project runs in CI. Enforces PEP 8 and catches unused imports.

---

## G

**GenericAPIView** — the DRF base class that adds `get_queryset()`, `get_serializer()`, pagination, and filtering to `APIView`.

**get_or_create** — fetch a row or create it; returns `(obj, created)`. The engine behind [[Nested Serialization|nested tag writes]].

---

## H

**HSTS** — `Strict-Transport-Security`. Tells browsers never to use plain HTTP for this domain. Powerful and hard to undo — enable last.

---

## I

**Idempotent** ⭐ — running it twice has the same effect as running it once. `GET`, `PUT` and `DELETE` should be; `POST` usually isn't. Every [[9.Background Jobs with Celery|Celery task]] must be, because delivery is at-least-once.

**IDOR** ⭐ — Insecure Direct Object Reference. Changing an ID in a URL to reach someone else's data. OWASP API #1. Prevented by filtering `get_queryset()`.

**Isolation level** — how much one in-flight transaction can see of another. Postgres defaults to `READ COMMITTED`.

---

## L

**Lazy evaluation** ⭐ — a QuerySet builds SQL without running it. The query fires only when you iterate, slice with an index, call `len()`, or coerce to `bool`.

---

## M

**Mass assignment** — a client sending a field you didn't intend to accept (`is_staff: true`) and the serializer writing it. Prevented by an explicit `fields` list.

**Middleware** — a chain of wrappers around every Django request/response. Runs before DRF's view layer.

**Migration** — a Python file describing a schema change. Generated by `makemigrations`, applied by `migrate`. Commit them.

**Mixin** — a small class contributing one behaviour, combined with others via multiple inheritance. `ListModelMixin` adds `list()`.

**Mocking** — replacing a real object with a fake during a test so you can control its behaviour. See [[3.What Is Mocking]].

**MRO** — Method Resolution Order. The order Python searches base classes. Why `GenericViewSet` goes **last** in a mixin-based viewset.

---

## N

**N+1 query problem** ⭐ — one query for a list plus one per row for related data. Serializing 100 recipes with tags = 201 queries. See [[4.The N+1 Problem]].

**normalize_email** — Django's helper lowercasing the domain part of an email so `A@Example.COM` and `a@example.com` don't become two accounts.

---

## O

**on_commit** ⭐ — `transaction.on_commit(fn)` defers `fn` until the surrounding transaction actually commits. Where emails, webhooks and Celery tasks belong.

**OpenAPI** — the specification format describing a REST API. Swagger UI renders it.

**ORM** — Object-Relational Mapper. Python classes ↔ database tables.

**OWASP API Top 10** — the industry list of the most common API vulnerabilities. The spine of [[10.Security Checklist]].

---

## P

**perform_create** — the ViewSet hook where you inject server-side data on write: `serializer.save(user=self.request.user)`.

**prefetch_related** — a second query plus `WHERE id IN (…)`, joined in Python. For M2M and reverse FK.

**PROTECT** — `on_delete` behaviour: refuse to delete a parent that still has children.

---

## Q

**Q object** — a composable query fragment supporting `|` (OR), `&` (AND) and `~` (NOT).

**QuerySet** — a lazy, chainable, cacheable representation of a database query.

---

## R

**Reverse proxy** — a server in front of your app that forwards requests to it. nginx here. See [[3.nginx as a Reverse Proxy]].

**Router** — DRF component generating URL patterns from a ViewSet.

---

## S

**Savepoint** — a nested transaction marker. A nested `atomic()` block creates one, letting you roll back part of a transaction without losing all of it.

**select_for_update** — `SELECT … FOR UPDATE`, a row-level lock held until the transaction ends. For read-decide-write sequences.

**select_related** — a SQL `JOIN` fetching FK/OneToOne relations in the same query.

**Serialization** — model instance → Python primitives → JSON. The *read* direction.

**Signal** — a publish/subscribe hook letting code react to events like `post_save` without the sender knowing. See [[7.Signals]].

**Stateless** ⭐ — the server keeps no session data between requests; everything needed is in the request itself. JWT is stateless; DRF tokens are not.

---

## T

**TDD** — write the failing test, write the code, refactor. See [[Test Driven Development]].

**Throttling** — capping request rate per client. Returns `429`. See [[2.Throttling and Rate Limiting]].

**Token authentication** — client exchanges credentials once for a token, then sends `Authorization: Token <key>`. Note: `Token`, not `Bearer`.

**Twelve-Factor App** — a set of conventions for building deployable services. Factor III (config in the environment) drives [[4.Environment Variables and Secrets]].

---

## U

**uWSGI** — the production WSGI server running your Django app across multiple worker processes.

---

## V

**ViewSet** — a class grouping the actions for a resource, wired to URLs by a router.

---

## W

**wait_for_db** — the custom management command that blocks until Postgres accepts connections. Solves the container start-order race.

**WSGI** ⭐ — the Python standard interface between a web server and a web framework. Django exposes a WSGI callable at `app/wsgi.py`.

**write_only** — a serializer field accepted on input but never returned on output. What keeps passwords out of responses.
