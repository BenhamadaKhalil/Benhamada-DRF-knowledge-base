## 🎯 The five snippets you'll paste most

**Scope a queryset to the caller**
```python
def get_queryset(self):
    return self.queryset.filter(user=self.request.user).order_by("-id")
```

**Set the owner from the token, never the payload**
```python
def perform_create(self, serializer):
    serializer.save(user=self.request.user)
```

**Different serializer per action**
```python
def get_serializer_class(self):
    if self.action == "list":
        return serializers.RecipeSerializer
    return serializers.RecipeDetailSerializer
```

**Hide the password on the way out**
```python
extra_kwargs = {"password": {"write_only": True, "min_length": 5}}
```

**Kill the N+1**
```python
.select_related("user").prefetch_related("tags", "ingredients")
```
