# 🎛️ ورقة ViewSet والـ Router

![[drf-view-hierarchy.svg]]

> 🇬🇧 النسخة الإنجليزية: [[EN/20.Reference/3.ViewSet and Router Cheatsheet|ViewSet and Router Cheatsheet]]

---

## 🪜 اختر الدرجة

| تحتاج | استخدم |
| --- | --- |
| CRUD كامل على نموذج | `ModelViewSet` |
| CRUD ناقص الإنشاء | mixins + `GenericViewSet` |
| مورد للقراءة فقط | `ReadOnlyModelViewSet` |
| مسار مجموعة (`GET`+`POST`) | `ListCreateAPIView` |
| مسار تفصيل | `RetrieveUpdateDestroyAPIView` |
| نقطة نهاية شاذّة (`/token/`) | `APIView` |
| دالّة سريعة | `@api_view(["GET"])` |

---

## 📦 العروض العامّة

| الصنف | الطرق | شكل المسار |
| --- | --- | --- |
| `CreateAPIView` | POST | `/things/` |
| `ListAPIView` | GET | `/things/` |
| `ListCreateAPIView` | GET, POST | `/things/` |
| `RetrieveAPIView` | GET | `/things/{id}/` |
| `RetrieveUpdateAPIView` | GET, PUT, PATCH | `/things/{id}/` |
| `RetrieveUpdateDestroyAPIView` | + DELETE | `/things/{id}/` |
| `DestroyAPIView` | DELETE | `/things/{id}/` |

## 🧩 الـ Mixins

| الـ Mixin | يُضيف | HTTP |
| --- | --- | --- |
| `ListModelMixin` | `list()` | GET (مجموعة) |
| `CreateModelMixin` | `create()` | POST |
| `RetrieveModelMixin` | `retrieve()` | GET (تفصيل) |
| `UpdateModelMixin` | `update()`، `partial_update()` | PUT, PATCH |
| `DestroyModelMixin` | `destroy()` | DELETE |

```python
class TagViewSet(mixins.DestroyModelMixin,
                 mixins.UpdateModelMixin,
                 mixins.ListModelMixin,
                 viewsets.GenericViewSet):     # ← الأساس دائمًا أخيرًا
    ...
```

## 🔄 العمليات ← HTTP

| العملية | الطريقة | المسار | تفصيل؟ |
| --- | --- | --- | --- |
| `list` | GET | `/recipes/` | لا |
| `create` | POST | `/recipes/` | لا |
| `retrieve` | GET | `/recipes/{pk}/` | نعم |
| `update` | PUT | `/recipes/{pk}/` | نعم |
| `partial_update` | PATCH | `/recipes/{pk}/` | نعم |
| `destroy` | DELETE | `/recipes/{pk}/` | نعم |

## 🧭 الـ Routers

```python
# app/recipe/urls.py
router = DefaultRouter()
router.register("recipes", views.RecipeViewSet)
router.register("tags", views.TagViewSet)

app_name = "recipe"

urlpatterns = [path("", include(router.urls))]
```

| الـ Router | يمنحك |
| --- | --- |
| `SimpleRouter` | المسارات فقط |
| `DefaultRouter` | المسارات **مع** صفحة جذر تسرد كل نقاط النهاية |

### الأسماء المُولَّدة

| المُسجَّل | اسم القائمة | اسم التفصيل |
| --- | --- | --- |
| `register("recipes", ...)` | `recipe:recipe-list` | `recipe:recipe-detail` |
| `register("tags", ...)` | `recipe:tag-list` | `recipe:tag-detail` |

```python
reverse("recipe:recipe-list")
reverse("recipe:recipe-detail", args=[recipe.id])
```

> [!WARNING] قطعتان ينساهما الجميع
> - **`app_name = "recipe"`** — بدونها يرمي `reverse("recipe:…")` خطأ `NoReverseMatch`، والرسالة **لا تذكر `app_name` إطلاقًا**، ولهذا يُكلّف هذا الخطأ ساعة.
> - **خاصيّة `queryset`** على الصنف — يستنتج منها الـ router الاسم الأساسي. بدونها: `basename argument not specified`.

## ⚡ العمليات المخصّصة

```python
@action(methods=["POST"], detail=True, url_path="upload-image")
def upload_image(self, request, pk=None):
    recipe = self.get_object()
    serializer = self.get_serializer(recipe, data=request.data)
    serializer.is_valid(raise_exception=True)
    serializer.save()
    return Response(serializer.data, status=status.HTTP_200_OK)
```

| المعامل | الأثر |
| --- | --- |
| `detail=True` | `/recipes/{pk}/upload-image/` |
| `detail=False` | `/recipes/upload-image/` |
| `url_path` | مقطع المسار |
| `permission_classes` | صلاحيات لهذه العملية وحدها |
| `serializer_class` | مُسلسِل لهذه العملية وحدها |

## 🪝 الخطّافات

```python
class RecipeViewSet(viewsets.ModelViewSet):
    serializer_class = serializers.RecipeDetailSerializer
    queryset = Recipe.objects.all()
    authentication_classes = [TokenAuthentication]
    permission_classes = [IsAuthenticated]

    def get_queryset(self):
        """ما الذي يراه هذا الطلب."""
        return (
            self.queryset
            .filter(user=self.request.user)
            .prefetch_related("tags", "ingredients")
            .order_by("-id")
        )

    def get_serializer_class(self):
        """أيّ شكل، حسب العملية."""
        if self.action == "list":
            return serializers.RecipeSerializer
        return self.serializer_class

    def perform_create(self, serializer):
        """حقن بيانات من الخادم عند الكتابة."""
        serializer.save(user=self.request.user)

    def get_permissions(self):
        """صلاحيات حسب العملية — تُعيد **كائنات**."""
        if self.action == "destroy":
            return [IsAuthenticated(), IsOwner()]
        return [IsAuthenticated()]
```

| الخطّاف | يُستدعى | استخدمه لـ |
| --- | --- | --- |
| `get_queryset()` | كل طلب قائمة/تفصيل | **حصر البيانات على المستخدم** |
| `get_serializer_class()` | كل طلب | تغيير الشكل حسب العملية |
| `perform_create(serializer)` | POST | ضبط ما لا يجوز للعميل إرساله |
| `perform_update(serializer)` | PUT/PATCH | نفس الشيء + إبطال الذاكرة المؤقّتة |
| `perform_destroy(instance)` | DELETE | الحذف الناعم، تنظيف الملفات |
| `get_permissions()` | كل طلب | تفويض حسب العملية |
| `get_object()` | طلبات التفصيل | بحث مخصّص (مثل `/me/`) |

## 🎯 الخلاصة في ثلاثة أسطر

```python
def get_queryset(self):
    return self.queryset.filter(user=self.request.user)     # من يستطيع أن يرى

def perform_create(self, serializer):
    serializer.save(user=self.request.user)                 # من يملك

permission_classes = [IsAuthenticated]                      # من يستطيع أن يسأل
```

اضبط هذه الثلاثة بشكل صحيح وتتبعها معظم صحّة الـ API.
