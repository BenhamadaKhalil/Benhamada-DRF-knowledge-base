## 🎣 الجلب

```python
Recipe.objects.all()                          # مجموعة كسولة — لا استعلام بعد
Recipe.objects.get(id=1)                      # كائن واحد أو استثناء
Recipe.objects.filter(user=user)              # WHERE
Recipe.objects.exclude(price=0)               # WHERE NOT
Recipe.objects.first()  /  .last()            # LIMIT 1
Recipe.objects.count()                        # SELECT COUNT(*)
Recipe.objects.exists()                       # SELECT 1 … LIMIT 1
```

| `get()` يرمي | متى |
| --- | --- |
| `Recipe.DoesNotExist` | لا نتيجة |
| `Recipe.MultipleObjectsReturned` | أكثر من نتيجة |

```python
from django.shortcuts import get_object_or_404
recipe = get_object_or_404(Recipe, id=1, user=request.user)     # ← 404 لا 500
```

> [!TIP] `exists()` أفضل من `count()` أفضل من `len()`
> ```python
> if Recipe.objects.filter(user=user).exists():   # ✅ LIMIT 1
> if Recipe.objects.filter(user=user).count():    # ⚠️ COUNT كامل
> if len(Recipe.objects.filter(user=user)):       # ❌ يجلب كل الصفوف إلى بايثون
> ```

## 🔎 عمليات البحث

| العملية | SQL | مثال |
| --- | --- | --- |
| `exact` | `=` | `filter(title__exact="كاري")` |
| `iexact` | `ILIKE` | `filter(email__iexact="A@B.com")` |
| `contains` / `icontains` | `LIKE '%x%'` | `filter(title__icontains="كار")` |
| `startswith` / `endswith` | `LIKE 'x%'` | `filter(title__startswith="ك")` |
| `in` | `IN (…)` | `filter(id__in=[1, 2, 3])` |
| `gt` `gte` `lt` `lte` | `> >= < <=` | `filter(price__lte=10)` |
| `range` | `BETWEEN` | `filter(price__range=(5, 20))` |
| `isnull` | `IS NULL` | `filter(link__isnull=True)` |
| `year` `month` `day` | أجزاء التاريخ | `filter(created__year=2026)` |

عبور العلاقات بـ `__`:

```python
Recipe.objects.filter(tags__name="نباتي")
Recipe.objects.filter(user__email__endswith="@example.com")
```

> [!WARNING] `filter()` متسلسلة ≠ `filter()` واحدة على علاقة متعدّدة
> ```python
> # صفوف يكون فيها وسمٌ **واحد** نباتيًا وحلوى معًا — غالبًا صفر
> Recipe.objects.filter(tags__name="نباتي", tags__name="حلوى")
>
> # صفوف لها وسم نباتي **و** (منفصلًا) وسم حلوى — ما تقصده غالبًا
> Recipe.objects.filter(tags__name="نباتي").filter(tags__name="حلوى")
> ```
> كل `.filter()` على علاقة ManyToMany تُنشئ `JOIN` خاصًّا بها. هذا التمييز يلدغ الجميع مرة واحدة.

## 🔀 `Q` — أو، و، ليس

```python
from django.db.models import Q

Recipe.objects.filter(Q(price__lt=5) | Q(time_minutes__lt=10))       # OR
Recipe.objects.filter(Q(price__lt=5) & Q(user=user))                 # AND
Recipe.objects.filter(~Q(link=""))                                   # NOT
```

بناء ديناميكي:

```python
query = Q(user=request.user)
if search:
    query &= Q(title__icontains=search)
if max_price:
    query &= Q(price__lte=max_price)

Recipe.objects.filter(query)
```

## 🧮 `F` — أشِر إلى عمود داخل الاستعلام

```python
from django.db.models import F

Recipe.objects.filter(price__gt=F("time_minutes"))         # قارن عمودين
Recipe.objects.filter(id=1).update(views=F("views") + 1)   # تحديث ذرّي، بلا سباق
Recipe.objects.update(price=F("price") * 1.1)              # حساب على كل الصفوف
```

`F()` تعمل **داخل قاعدة البيانات**. النسخة التي تقرأ ثم تُعدّل ثم تكتب في بايثون تفقد تحديثات تحت التزامن.

## 📊 التجميع والتعليق

```python
from django.db.models import Count, Sum, Avg, Max, Min

# aggregate ← قاموس واحد للمجموعة كلها
Recipe.objects.aggregate(Avg("price"), Max("time_minutes"), Count("id"))

# annotate ← يُضيف خاصيّة لكل صفّ
Recipe.objects.annotate(tag_count=Count("tags")).filter(tag_count__gte=2)
```

> [!WARNING] العدّ المزدوج مع تعليقين
> `annotate(Count("tags"), Count("ingredients"))` يُضاعف الـ JOINs ويُضخّم الرقمين. استخدم `distinct=True`:
> ```python
> .annotate(t=Count("tags", distinct=True), i=Count("ingredients", distinct=True))
> ```

## 🚀 الأداء

```python
.select_related("user")                     # FK / OneToOne ← JOIN
.prefetch_related("tags", "ingredients")    # M2M / عكسية ← استعلام ثانٍ
.fetch_mode(models.FETCH_PEERS)             # 6.1 — تحميل تفاعلي
.only("id", "title")                        # هذه الأعمدة فقط
.values("id", "title")                      # قواميس لا كائنات
.values_list("id", flat=True)               # قائمة مسطّحة
.iterator()                                 # بثّ — بلا تخزين النتائج
```

> [!WARNING] مهجورات Django 6.1 — تُحذَف في 7.0
> ```python
> Recipe.objects.select_related()             # ❌ بلا معاملات
> Recipe.objects.values_list(flat=True)       # ❌ بلا اسم حقل
> ```
> وأيضًا: `first()` و`last()` **لم تعُد تُرتّب تلقائيًا** بالمفتاح الأساسي حين يُمسَح الترتيب.

**العمليات الجماعية** — استعلام واحد بدل N:

```python
Recipe.objects.bulk_create([Recipe(...), Recipe(...)])
Recipe.objects.filter(price=0).update(price=1)        # بلا save()، بلا إشارات
```

> [!CAUTION] العمليات الجماعية تتجاوز `save()` والإشارات
> ولا تُشغّل `auto_now`. إن كنت تعتمد على أيٍّ منها، استخدم حلقة — أو أبطِل الذاكرة المؤقّتة يدويًا.

## ⏳ الكسل — متى يعمل الاستعلام فعلًا؟

| يُطلق استعلامًا | لا يُطلق |
| --- | --- |
| `list(qs)` | `qs.filter(...)` |
| `for r in qs:` | `qs.order_by(...)` |
| `len(qs)` | `qs[5:10]` *(تقطيع)* |
| `bool(qs)` | الإسناد |
| `qs[0]` *(فهرسة)* | |
| `repr(qs)` — **ولهذا «يعمل» في الـ shell** | |
