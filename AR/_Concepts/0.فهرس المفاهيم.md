# 🧩 فهرس المفاهيم

> تعريفات قصيرة للأفكار التي تتكرّر في كل قسم. كل صفحة تُقرأ في دقيقة، وتُحيلك إلى الملاحظة التي تعالج الموضوع بعمق.

---

## 🌐 الإطار

| المفهوم | بسطر واحد |
| --- | --- |
| **Django REST Framework** 🇬🇧 | الطبقة التي تُضيف المُسلسِلات والمصادقة والصلاحيات فوق Django |
| [[مجموعات العروض ViewSet]] | صنف واحد يجمع كل عمليات مورد واحد |
| **APIView** 🇬🇧 | تكتب `get()` و`post()` بنفسك — لنقاط النهاية غير القياسية |

## 🧬 المُسلسِلات

| المفهوم | بسطر واحد |
| --- | --- |
| [[المُسلسِلات]] | نموذج ↔ JSON، مع التحقّق من الصحّة |
| [[الدالة get_or_create]] | المحرّك خلف الكتابة المتداخلة للوسوم |
| **Serializer Validation** 🇬🇧 | طبقات التحقّق الأربع، بالترتيب |

## 🔐 المصادقة والصلاحيات

| المفهوم | بسطر واحد |
| --- | --- |
| [[مصادقة التوكن]] | بيانات الاعتماد مرة واحدة ← توكن مرات كثيرة |
| [[الصلاحيات]] | من يُسمح له — والفخّ في نقاط نهاية القوائم |
| **JWT** 🇬🇧 | عديم الحالة، وثمن ذلك أنك لا تستطيع الإبطال |
| **Custom User Model** 🇬🇧 | أنجزه في اليوم الأول |

## 🗃️ البيانات

| المفهوم | بسطر واحد |
| --- | --- |
| [[مجموعات الاستعلام QuerySet]] | وعد بالاستعلام، لا نتيجة — والكسل هو المفتاح |
| **Django Models** 🇬🇧 | صنف واحد = جدول واحد |
| **Decimal vs Float** 🇬🇧 | لماذا المال لا يكون `float` أبدًا |

## 📖 اصطلاحات المصطلحات

هذه النسخة **لا تُعرِّب أسماء الكود**. الأسباب عملية: ستقرأ هذه الكلمات في الطرفية وفي رسائل الأخطاء وفي التوثيق الرسمي، وتعريبها يقطع الصلة بينها وبين ما تراه على الشاشة.

| اللاتيني | الشرح العربي عند أول ذكر |
| --- | --- |
| `serializer` | المُسلسِل |
| `queryset` | مجموعة الاستعلام |
| `middleware` | الوسيطة |
| `migration` | الترحيل |
| `endpoint` | نقطة النهاية |
| `viewset` | مجموعة العروض |
| `token` | التوكن / الرمز |
| `hash` | التجزئة |
| `cache` | التخزين المؤقّت |
| `throttling` | تحديد المعدّل |
| `constraint` | القيد |
| `signal` | الإشارة |
