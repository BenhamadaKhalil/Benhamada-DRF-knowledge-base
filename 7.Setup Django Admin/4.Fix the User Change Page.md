# Django Admin – Fix the User Change Page (fieldsets + readonly_fields)

## 🎯 Main Goal

Fix the error that happens when you click a user in Django Admin (the **user change/edit page** fails) by:

- writing a test first (TDD)
    
- customizing `UserAdmin` so it only uses fields that exist in your **custom User model**
    
- setting proper sections/layout using `fieldsets`
    
- making `last_login` read-only
    

---

## ✅ Step 1 — Add a Test for the Edit User Page

In `core/tests/test_admin.py`, add a new test under your existing “users listed” test.

### What we want to verify

The Django Admin “change user” page should load successfully (HTTP **200**).

### Admin URL for change page

Admin uses a predictable URL pattern:

- `admin:<app_label>_<model_name>_change`
    

For your user model:

- `admin:core_user_change`
    

But this URL requires a user ID, passed as args.

### Test structure (concept)

```python
def test_edit_user_page(self):
    """Test the edit user page works."""
    url = reverse('admin:core_user_change', args=[self.user.id])
    res = self.client.get(url)

    self.assertEqual(res.status_code, 200)
```

✅ This test is simple on purpose: we only care that the page loads.

### Expected result

The test fails initially because the admin change form is still using default fields (like `username`) that your custom model doesn’t have.

---

## ❌ Why It Fails (Root Cause)

You are inheriting from Django’s `BaseUserAdmin`, which expects the default user fields.

But your custom user model likely uses:

- `email` instead of `username`
    
- custom fields like `name`
    
- permissions fields (`is_active`, `is_staff`, `is_superuser`)
    
- system fields like `last_login`
    

So Django tries to render fields that don’t exist → error.

---

## ✅ Step 2 — Customize `UserAdmin` to Match Your Model

Go to:

`core/admin.py`

Inside your `UserAdmin` class, add **fieldsets** so the change page uses only real fields.

### 1) Import translation helper (best practice)

```python
from django.utils.translation import gettext_lazy as _
```

Why?

- Django admin supports translations
    
- Using `_()` is standard and keeps the app ready for future i18n
    

---

## 🧩 Add `fieldsets`

`fieldsets` controls the layout of the edit/change page in sections.

It’s a tuple of sections, where each section is:

- `(section_title, {'fields': (...)})`
    

### Recommended structure used in the lesson

- No title section: email + password
    
- Permissions section: is_active, is_staff, is_superuser
    
- Important dates: last_login
    

Conceptually:

```python
fieldsets = (
    (None, {'fields': ('email', 'password')}),
    (_('Permissions'), {'fields': ('is_active', 'is_staff', 'is_superuser')}),
    (_('Important dates'), {'fields': ('last_login',)}),
)
```

✅ Key idea: **only include fields that exist** in your model.

This overrides the default Django admin config that includes `username`.

---

## 🔒 Add `readonly_fields`

Make `last_login` read-only:

```python
readonly_fields = ['last_login']
```

So admin users can see the last login timestamp but can’t edit it.

---

## ✅ Step 3 — Run Tests Again

After updating `fieldsets` + `readonly_fields`, re-run:

```bash
docker compose run --rm app sh -c "python manage.py test"
```

Now the new test should pass (edit page returns 200).

---

## ✅ Confirm in Browser

Refresh the admin page, click a user again.

Now it loads successfully, and you’ll see the admin form grouped into sections (like “Permissions”, “Important dates”).

If you change section headings in `fieldsets` and refresh, you’ll see the UI update — confirming these settings control the admin layout.

---

## 🧠 Key Takeaways

- **TDD flow**: write failing test → implement fix → tests pass
    
- Admin change page failed because default `BaseUserAdmin` expects fields your custom model doesn’t have
    
- `fieldsets` is the main tool to fix the change form layout
    
- `gettext_lazy as _` is Django’s standard for translatable admin labels
    
- `readonly_fields` protects system-generated fields from being edited
