# 🔐 2) Configured Docker Hub Authentication (for CI/CD)

Inside GitHub → **Settings → Secrets**, we added:

- `DOCKERHUB_USER`
    
- `DOCKERHUB_TOKEN`
    

🧠 Why?

Because:

- Docker Hub has pull rate limits
    
- GitHub Actions runs on shared servers
    
- Without authentication, builds may fail
    
- With authentication → higher pull limit (200 per 6 hours)
    

This prepares us for CI/CD later.

# 🐳 3) Created Docker Configuration

We added:

## 📄 Dockerfile

Defines:

- Python base image (3.9-alpine)

## 📄 docker-compose.yml

Defines:

- Service: `app`
    
- Build context
    
- Port mapping (8000:8000)
    
- Volume mapping (`./app:/app`)
    
- Default run command

# 📦 4) Added Requirements Files

We created:

- `requirements.txt` → production dependencies
    
- `requirements.dev.txt` → development-only tools (Flake8)
    

We also:

- Added conditional install logic in Dockerfile
    
- Used build argument `DEV=true` for development mode
    

---

# 🧹 5) Configured Linting (Flake8)

We:

- Installed Flake8 in dev mode
    
- Created `app/.flake8` config
    
- Excluded:
    
    - migrations
        
    - **pycache**
        
    - manage.py
        
    - settings.py
        

We ran:

```bash
docker compose run --rm app sh -c "flake8"
```

✅ No output = No lint errors

---

# 🌱 6) Created the Django Project (Inside Docker)

We ran:

```bash
docker compose run --rm app sh -c "django-admin startproject app ."
```

Important:

- The `.` prevents nested directories
    
- Volume mapping synced files automatically
    

Result:

- Django project created inside `app/`
    

---

# 🚀 7) Ran the Development Server

We started the server with:

```bash
docker compose up
```

Then accessed:

```
http://127.0.0.1:8000
```

✅ Django welcome page appeared  
✅ Logs showed requests  
✅ CTRL + C stopped the server
