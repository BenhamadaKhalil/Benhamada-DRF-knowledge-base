# 🧹 Configure Flake8 Linting (Dev Requirements + Docker Build Args) — Obsidian Notes

> 🎯 Goal: Install **Flake8** only in **development**, rebuild the Docker image correctly, add a `.flake8` config, then verify linting runs with no errors.

---

# 1) 📄 Create `requirements.dev.txt` (Dev-only dependencies)

📍 In the **root** of the project, create:

```
requirements.dev.txt
```

Add Flake8 with a safe version range:

```txt
flake8>=3.9.2,<3.10
```

✅ This gives you:

- Latest **patch** updates (bug/security fixes)
    
- No jump to the next minor version (avoids breaking changes)
    

---

# 2) 🎯 Why split dev requirements?

> [!info] Why not put Flake8 in normal requirements?  
> Flake8 is only needed for **development**, not in production.

✅ Benefits:

- 🪶 Smaller production image
    
- 🔒 Fewer packages = less attack surface
    
- 📦 Cleaner dependency management
    

---

# 3) ⚙️ Add a Build Argument in `docker-compose.yml`

We want Docker Compose (dev environment) to tell Docker:

✅ “Install dev dependencies too”

Inside `docker-compose.yml`, under `build:`, add `args`:

```yaml
services:
  app:
    build:
      context: .
      args:
        - DEV=true
```

> [!note] Meaning  
> When building via Docker Compose, it passes `DEV=true` to the Dockerfile.

---

# 4) 🧱 Update the `Dockerfile` to support DEV mode

## ✅ Step A — Copy the dev requirements into the image

Add this line near the existing requirements copy:

```dockerfile
COPY ./requirements.dev.txt /tmp/requirements.dev.txt
```

---

## ✅ Step B — Add the build arg with a default value

Add this line **before** the `RUN ...` block:

```dockerfile
ARG DEV=false
```

Meaning:

- Default: `DEV=false` (production-safe)
    
- Docker Compose overrides it: `DEV=true` (dev build)
    

---

## ✅ Step C — Conditionally install dev dependencies

Inside the big `RUN` block, add an `if` statement **after installing main requirements**, like this:

```dockerfile
RUN python -m venv /py && \
    /py/bin/pip install --upgrade pip && \
    /py/bin/pip install -r /tmp/requirements.txt && \
    if [ "$DEV" = "true" ]; then /py/bin/pip install -r /tmp/requirements.dev.txt ;\ fi && \
    rm -rf /tmp && \
    adduser \
        --disabled-password \
        --no-create-home \
        django-user
```

> [!important] Common mistake  
> Make sure the path is **`/tmp/requirements.dev.txt`**  
> The instructor mentioned they forgot `/tmp/` and Docker failed.

---

# 5) 🔁 Rebuild the image to apply changes

Run:

```bash
docker compose build
```

✅ If it builds successfully → your Dockerfile + compose config are correct.

---

# 6) 🛠️ Add Flake8 Configuration File

📍 **Important:** Create this file **inside the `app/` folder**, not in the project root.

Create:

```
app/.flake8
```

Add:

```ini
[flake8]
exclude = migrations, __pycache__, manage.py, settings.py
```

---

## 🧠 Why exclude these files?

- `migrations/` → auto-generated by Django
    
- `__pycache__/` → auto-generated Python cache
    
- `manage.py` → Django generated utility script
    
- `settings.py` → often contains long lines, mostly template code
    

✅ Goal: lint **your code**, not template-generated boilerplate.

---

# 7) ✅ Test Flake8 is working

Run linting:

```bash
docker compose run --rm app sh -c "flake8"
```

### Expected result:

- If there is **no output** → ✅ No lint errors, everything is configured correctly.
