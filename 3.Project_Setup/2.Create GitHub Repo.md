# 🧑‍💻 Create GitHub Repo + Connect Docker Hub (Secrets) — Obsidian Notes

> 🎯 Goal: Create a GitHub repository for the project, clone it locally, then add Docker Hub credentials as GitHub Secrets (for later GitHub Actions).

---

## ✅ 0) Accounts You Must Have

- 🐙 **GitHub account** (to host the code)
    
- 🐳 **Docker Hub account** (to pull Docker images + avoid rate limit issues)
    

> [!tip] Why Docker Hub account matters  
> Docker Hub has pull limits. Logging in increases the allowed pulls and prevents CI (GitHub Actions) from failing later.

---

# 🐙 1) Create a New GitHub Repository

## Steps

1. Log in to GitHub
    
2. Click **New repository**
    
3. Set:
    
    - 📛 **Repository name:** `recipe-app-api`
        
    - 📝 **Description:** `Recipe API project`
        
    - 🌍 **Visibility:** Public (easier to share in Q&A)
        
4. ✅ Check:
    
    - `Add a README file`
        
    - `Add .gitignore` → choose **Python**
        
5. Click **Create repository**
    

---

# 🖥️ 2) Clone the Repository Locally

## Steps

1. Copy the repo **clone URL** (SSH or HTTPS)
    
2. Open terminal (or on Windows use CMD / PowerShell / Git Bash)
    
3. Go to your workspace folder
    

Example:

```bash
cd Documents/Workspace
```

4. Clone the repo:
    

```bash
git clone <REPO_URL>
```

✅ Result: The project folder is now on your machine.

---

# 🔐 3) Create a Docker Hub Access Token (Best Practice)

> [!important] Use tokens, not passwords  
> Tokens are safer than using your Docker Hub password in GitHub.

## Steps (Docker Hub)

1. Go to Docker Hub → **Account Settings**
    
2. Open **Security**
    
3. Click **New Access Token**
    
4. Name it something clear (so you can recognize it later), e.g.:
    
    - `recipe-app-api`
        
5. Click **Create**
    

> [!warning] You only see the token once  
> Copy it immediately. If you lose it, delete the token and create a new one.

---

# 🧩 4) Add Docker Hub Credentials to GitHub Secrets

These secrets will be used later by **GitHub Actions** to log in to Docker Hub before pulling images.

## Where to add secrets

GitHub Repo → **Settings** → **Secrets** (or **Secrets and variables**) → **Actions** → **New repository secret**

---

## ✅ Secret #1: Docker Hub Username

- **Name:** `DOCKER_HUB_USER`
    
- **Value:** your Docker Hub username
    

Click **Add secret**

---

## ✅ Secret #2: Docker Hub Token

- **Name:** `DOCKER_HUB_TOKEN`
    
- **Value:** paste the access token you generated
    

Click **Add secret**

> [!warning] Names must match exactly  
> The course will reference these names in the workflow files later.

---

# 🧠 5) Why We Do This (Quick Explanation)

## Problem

GitHub Actions runs on shared servers → Docker Hub pull limits can be reached quickly.

## Solution

Authenticate with Docker Hub using:

- `DOCKER_HUB_USER`
    
- `DOCKER_HUB_TOKEN`
    

✅ This increases allowed pulls and makes CI stable.
