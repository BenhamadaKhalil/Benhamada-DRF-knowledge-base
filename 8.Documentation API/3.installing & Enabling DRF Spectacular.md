# 🎥 Installing & Enabling DRF Spectacular (Swagger Docs Setup) ⚙️📚

---

## 🎯 Objective

In this lesson we will:

- Install **DRF Spectacular** into the project ✅
- Rebuild Docker so the dependency is included 🐳
- Enable **Django REST Framework** + **drf_spectacular** inside `INSTALLED_APPS`
- Configure DRF to generate schemas using **OpenAPI AutoSchema** 🧠

---

## 📦 Step 1 — Add Package to Requirements

Open:

- `requirements.txt`

Add at the bottom:

```txt
drf-spectacular>=0.15.1,<0.16
```

📌 Why this format?

- `>=0.15.1` ensures at least that version
- `<0.16` prevents breaking changes from future versions  
  (keeps the course stable ✅)

---

## 🐳 Step 2 — Rebuild Docker Image

Since we’re using Docker, adding a dependency means we need to rebuild the image so it gets installed.

Run:

```bash
docker-compose build
```

✅ If build succeeds → the package is now installed in the container.

---

## ⚙️ Step 3 — Enable Apps in Django Settings

Open:

- `app/app/settings.py`

Go to:

### ✅ `INSTALLED_APPS`

Add these:

```python
'rest_framework',
'drf_spectacular',
```

📌 Note:  
Even if Django REST Framework is installed in Python packages, it **won’t work** unless it is enabled in `INSTALLED_APPS`.

---

## 🧠 Step 4 — Configure DRF Schema Generator

At the bottom of `settings.py`, add:

```python
REST_FRAMEWORK = {
    'DEFAULT_SCHEMA_CLASS': 'drf_spectacular.openapi.AutoSchema',
}
```

### ✅ Why this is needed?

This tells DRF:

- “When generating the API schema, use DRF Spectacular’s AutoSchema class.”

Because DRF can support different schema generators, but we want:

- OpenAPI schema ✅
- Generated via drf_spectacular ✅

⚠️ Very important:
- Spelling must be correct
- Otherwise schema generation won’t work 🚫

## 📌 Key Takeaways

- Add `drf-spectacular` to requirements and rebuild Docker
- Enable both `rest_framework` and `drf_spectacular` in `INSTALLED_APPS`
- Set `DEFAULT_SCHEMA_CLASS` to `drf_spectacular.openapi.AutoSchema`
- Small spelling mistakes here = docs won’t generate 😅
